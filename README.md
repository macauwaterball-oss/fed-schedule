# FED 排課系統

純前端排課管理工具，用於大專體育課程的教師、場地、課表編排。

## 功能

- **課程管理** — 輸入學生人數，自動計算所需班數
- **教師管理** — 16 位教師，設定技能、偏好時段、每日上限
- **場地管理** — 7 個場地，每個場地有容許的運動項目
- **授課配置** — 18 組教師×運動×班數配置
- **課表檢視** — 6 時段 × 5 天彩色課表，支援拖拉調整
- **自動排課** — 依優先次序、偏好、場地、每日上限自動排列
- **衝突檢查** — 拖拉時自動檢查教師撞堂、場地衝突、FRI 17:30 限制
- **Excel 匯出** — 總課表、教師列表、場地列表、教師課表 4 種格式
- **JSON 備份** — 匯出/匯入全部資料，支援 localStorage 持久化

## 時間段

| 代號 | 時間 |
|------|------|
| S1 | 09:30 - 11:15 |
| S2 | 11:30 - 13:15 |
| S3 | 13:30 - 15:15 |
| S4 | 15:30 - 17:15 |
| S5 | 17:30 - 19:15 |
| S6 | 19:30 - 21:15 |

## 技術

- 純 HTML + CSS + JavaScript（無外部依賴）
- 所有資料內嵌於 `js/app.js` 的 `DEFAULT_DATA`
- Excel 匯出使用純 JS 生成 `.xls`（HTML table 格式）
- 資料持久化使用 `localStorage`

## 啟動

```bash
# 方法一：用瀏覽器直接開啟
open index.html

# 方法二：用 Python HTTP Server
python -m http.server 8080
# 然後開啟 http://localhost:8080
```

## 使用說明

1. 在「課程管理」分頁輸入每科學生人數，系統自動計算班數
2. 在「授課配置」分頁為每位教師分配運動項目和班數
3. 點擊「⚡ 自動排課」讓系統依規則自動排列
4. 在「課表檢視」分頁手動拖拉微調（系統會檢查衝突）
5. 在「匯出 Excel」分頁下載課表

## 規則

- 每位教師每日最多 2 堂課
- 同一時段不能有兩位教師共用同一場地
- 同一教師不能同時出現在兩個課堂
- 週五 S5（17:30）和 S6（19:30）不排課
- 教師只教其技能範圍內的運動
- 運動只能在相容場地進行
